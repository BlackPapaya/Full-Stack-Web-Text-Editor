#  FULL-STACK WEB TEXT EDITOR APP

No cloud server needed, can be saved locally as text files.

##  About the project

- Full-Stack Project to learn
- A simple Text Editor that can be saved in the Database (SQLite) or downloaded locally
- **Frontend:** HTML, CSS, JS
- **Backend:** Spring Boot (Java), SQLite
- A personal touch of a Text Editor

##  Features
- Very simple but nice UI
- Easy to use
- Simple source-code to copy and adjust
- Modular so you can add your own code too

##  Requirements

- JDK 18+ (21 was used)
- Gradle
- Browser
- Text editor + IDE
